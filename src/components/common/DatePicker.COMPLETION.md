## API 接口

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| modelValue | Date \| null | null | 选中的日期 |
| placeholder | string | '选择日期' | 占位符 |
| disabled | boolean | false | 是否禁用 |
| enableTime | boolean | false | 启用时间选择 |
| showShortcuts | boolean | true | 显示快捷选项 |
| ariaLabel | string | '日期选择器' | ARIA 标签 |
| minDate | Date | undefined | 最小日期 |
| maxDate | Date | undefined | 最大日期 |

### Events

| 事件 | 参数 | 说明 |
|------|------|------|
| update:modelValue | Date \| null | 日期变化 |
| change | Date \| null | 日期变化 |

## 使用示例

```vue
<template>
  <!-- 基础用法 -->
  <DatePicker v-model="date" placeholder="选择日期" />

  <!-- 日期时间选择 -->
  <DatePicker 
    v-model="dateTime" 
    :enable-time="true"
    placeholder="选择日期和时间" 
  />

  <!-- 日期范围限制 -->
  <DatePicker 
    v-model="limitedDate"
    :min-date="new Date()"
    :max-date="maxDate"
  />
</template>
```
