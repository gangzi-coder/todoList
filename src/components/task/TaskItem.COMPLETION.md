## 实现内容

### 1. 核心功能

✅ **任务信息显示**
- 任务标题
- 完成复选框
- 优先级标识（🔴高 🟡中 🟢低）
- 所属项目（带颜色标识）
- 截止日期（相对时间格式）
- 标签列表

✅ **状态标识**
- 过期任务：红色左边框 + "已过期"徽章
- 即将到来任务（7天内）：橙色左边框
- 已完成任务：标题删除线 + 降低透明度

✅ **交互功能**
- 点击复选框切换完成状态
- 点击任务区域触发编辑
- 拖拽排序支持（仅未完成任务）
- 悬停效果和过渡动画

✅ **可访问性**
- ARIA 标签支持
- 键盘导航（Tab、Enter、Space）
- 焦点指示器
- 高对比度模式支持
- 减少动画模式支持

## 技术实现

### 组件结构

```
TaskItem
├── 复选框区域
│   └── 完成复选框
├── 内容区域
│   ├── 标题行
│   │   ├── 任务标题
│   │   └── 优先级标识
│   └── 元数据行
│       ├── 项目信息
│       ├── 截止日期
│       └── 标签列表
└── 拖拽手柄
```

### 关键技术点

1. **日期处理**
   - 使用 `date.ts` 工具函数
   - 支持相对时间显示（今天、明天、X天后）
   - 自动判断过期和即将到来状态

2. **项目信息**
   - 从 `projectStore` 获取项目数据
   - 显示项目颜色标识

3. **拖拽功能**
   - 使用原生 HTML5 拖拽 API
   - 仅对未完成任务启用
   - 提供视觉反馈

4. **响应式设计**
   - 桌面端：完整功能
   - 移动端：隐藏拖拽手柄，优化触摸交互
